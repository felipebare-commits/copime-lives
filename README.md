# COPIME Lives (v1)
Camada simples sobre o VDO Ninja. Sem build, sem servidor: só arquivos estáticos.
- `index.html`: painel do apresentador (gera links de convidado, de OBS e convite WhatsApp).
- `convidado.html`: teste de conexão, entrada, reconexão automática, sala de espera.
Rodar local: `python3 -m http.server 8080` e abrir http://localhost:8080
Publicar de graça (precisa de https para câmera): GitHub Pages ou Netlify.
